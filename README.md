

# Система адаптивного планирования обучения (Frontend-часть)

## Установка всех зависимостей:
```
npm install
```

### Билд
```
npm run build
```

### Запуск на localhost (порт 8080)
```
npm run serve
```

### Описание части проекта 
Здесь находится готовая Frontend-часть: отрисованы базовый layout и страница авторизации, 404 ошибка.  
На странице Авторизации реализована логика обращения по API к серверу (смотри: src/common/api/auth.js)  
Обработка ошибок сначала происходит на стороне фронта (пустые поля), а в случае ошибок со стороны сервера - responseData = error?.response?.data  
Так же работает функция смены пароля (если флаг must_change_password), но при условии соблюдения требования к паролю.   
Если изначально созданный пароль админом не проверяется на сложность, и попытаться оставить его - будет приходит ошибка, что пароль не соответствует требованиям.  
По части "Список приоритетов" весь функционал реализован полностью на mock данных из pinia store (связь по API полностью отсутствует)  
Из-за проблем с CI/CD и файлом .env константа API_URL вынесена в src/router/constant.json
